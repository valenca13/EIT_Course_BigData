6.2 Extract land use amenities

  • Define Location
Code 
location <- "Sydney, Australia"
  • Create an OSM query for extracting amenities data
Code 
library(osmdata)
Data (c) OpenStreetMap contributors, ODbL 1.0. https://www.openstreetmap.org/copyright
Code 
amenities_query <- opq(location) |> 
  add_osm_feature(key = "amenity", value = c("restaurant", "bank", "bar"))

Note: We will use only two categories for simplicity of the example. Ideally, more types of amenities should be considered for analysis.

  • Extract the data
Code 
# Set an alternative Overpass server
set_overpass_url("https://overpass-api.de/api/interpreter")

amenities_data <- osmdata_sf(amenities_query)

## Extract land use amenities

* **Define Location**

```{r}
location <- "Sydney, Australia"
```

* Create an OSM query for extracting amenities data

```{r}
library(osmdata)
amenities_query <- opq(location) |> 
  add_osm_feature(key = "amenity", value = c("restaurant", "bank", "bar")) 
```

> **Note:** We will use only two categories for simplicity of the example. Ideally, more types of amenities should be considered for analysis. 

* Extract the data

```{r}
# Set an alternative Overpass server
set_overpass_url("https://overpass-api.de/api/interpreter")

amenities_data <- osmdata_sf(amenities_query)
```

```{r}
Sydney_main_roads = OSM_Sydney |>
```
